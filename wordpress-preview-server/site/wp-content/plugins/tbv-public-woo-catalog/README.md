# Public WooCommerce catalog bootstrap

A standalone, installable WordPress plugin for a narrowly scoped public REST `GET /wp-json/tbv-catalog/v1/products`. Requires WooCommerce. It is not activated or routed on any deployed site by adding these files. Public pages and versioned `page` / `per_page` arguments return only allowlisted parent and offer IDs, public names, warehouse, dose, pack, formulation, price, stock status and purchasability. Customer, order, payment, contact, internal supplier and arbitrary metadata are never returned.

Only published and publicly visible products, and published variations, are considered. Missing or unrecognized warehouse, dosage, pack or malformed price/stock are omitted rather than guessed. A page may have fewer results than `per_page` when products lack supported public offers; follow `has_more`. Prices remain decimal strings in WooCommerce's configured currency. Its `purchasable` value and pricing filters can be context-dependent. The default response is not cached.

The exact `_tbv_*` metadata mapping reflects the sanitized preview catalog; future WooCommerce imports need verified equivalent metadata/attributes. Physical stock, current prices and Woo cart/checkout integration are not validated by this plugin. To enable on a WordPress staging host, install and activate it under normal WordPress administration after appropriate review. The existing isolated preview server blocks REST routing, and this change deliberately does not expose a public route or modify production. Test the endpoint and catalog parity in a separate staging environment before any release.
