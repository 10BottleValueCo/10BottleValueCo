# Importer-to-theme integration — disposable fixture

This test exercises the source-built development importer, public catalog adapter, and staging theme together. It requires extracted, trusted local ZIPs and a specifically hash-checked sanitized WordPress/PHP-WASM fixture. It copies the fixture database and uploads into a temporary directory, deletes only products in that copy, imports twelve synthetic-key offers as drafts, repeats the dry run, then publishes the single synthetic parent only in that disposable copy so the public catalog and native Woo cart can be checked. It makes no real orders, uses no customer data, and does not publish products in a real store. HTTP and WordPress cron are disabled in the fixture.

Set absolute `TBV_WP_TEST_RUNTIME`, `TBV_THEME_DIRECTORY`, `TBV_CATALOG_DIRECTORY`, and `TBV_IMPORTER_DIRECTORY` to the trusted runtime and extracted plugin/theme directories, then run `node test.mjs`. The test verifies source-to-output IDs, price, dose, warehouse, pack, option labels and all twelve native cart variation IDs. It checks PHP/Woo behavior directly; it is not a browser, checkout, inventory, current price, live host, or complete visual parity test. Deleting or publishing real catalog items is outside the test's scope; never change the recognized database hash to use a real database.
