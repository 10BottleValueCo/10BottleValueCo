ШАГ 2 — SEO-АРХИТЕКТУРА
==================================================

Построй максимально сильную SEO-архитектуру, но без изменения видимого интерфейса.

Каждая существующая product page должна быть полноценной индексируемой страницей.

Для каждого продукта должны быть:

- уникальный URL;
- уникальный Title;
- уникальный Meta Description;
- уникальный canonical;
- уникальный Product Schema;
- правильный Open Graph;
- правильный Twitter Card;

- уникальная SEO-информация в metadata;
- правильный H1 уже существующей страницы;
- правильные internal links;
- отсутствие duplicate metadata.

Используй реальные существующие product pages.

НЕ создавай новые visible pages без моего разрешения.

==================================================
ШАГ 3 — TITLE
==================================================

Создай динамические Title.

Каждая продуктовая страница должна иметь свой Title.

Title должен:

- содержать название конкретного продукта;
- при необходимости содержать дозировку;
- естественно описывать страницу;
- не быть keyword stuffed;
- соответствовать Research Use Only;
- быть пригодным для Google SERP.

Пример:

BPC-157 5mg Research Peptide | 10BottleValueCo

или другой вариант, если анализ существующих данных показывает, что он лучше.

Не используй одинаковый Title для разных товаров.

Не вставляй десятки ключевых слов.

Не меняй Title без объективной причины.

==================================================
ШАГ 4 — META DESCRIPTION
==================================================

У каждой страницы должен быть уникальный Meta Description.

Description должен:

- соответствовать странице;
- дополнять Title;
- быть естественным;
- содержать релевантные термины;
- не быть keyword stuffed;
- не быть одинаковым для большого количества страниц.

Не утверждай, что какое-либо keyword имеет высокий search volume, если у тебя нет реальных данных.

==================================================
ШАГ 5 — URL
==================================================

Сделай product URLs максимально чистыми и понятными для Google.

Предпочтительно:

/bpc-157-5mg

вместо:

?product=bpc-157-5mg

Но:

- не ломай существующие ссылки;
- сохрани compatibility;
- правильно настрой redirects/canonical;
- не создавай duplicate URLs.

- query parameters;
- duplicate routes.
